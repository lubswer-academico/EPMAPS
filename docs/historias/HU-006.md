# HU-006 – Recuperación de registro interrumpido tras cierre inesperado

- **Identificador:** HU-006
- **Usuario:** Técnico de Campo
- **Prioridad para el negocio:** Media
- **Riesgo para desarrollo:** Medio

## Descripción

Como técnico de campo, quiero que la aplicación recuerde el progreso de una lectura si se cierra o reinicia accidentalmente durante el proceso multipantalla, para poder retomar la captura exactamente donde me quedé o descartarla sin perder tiempo reingresando información.

## Criterios de aceptación

### Escenario: Detección y ofrecimiento de recuperación de borrador pendiente
Dado que me encontraba a mitad del flujo de registro de un medidor y la aplicación se cerró abruptamente o por falta de batería
Cuando abro nuevamente la aplicación
Entonces el sistema detecta que existe un registro incompleto y me muestra un aviso destacado ofreciéndome continuar con la captura pendiente o descartarla

### Escenario: Continuación de la captura pendiente
Dado que el sistema detectó una captura en curso y me ofreció reanudarla
Cuando elijo la opción de continuar
Entonces la aplicación me lleva a la pantalla correspondiente restaurando todos los datos previamente ingresados (código de medidor, estado, lectura y foto si aplicaba)

### Escenario: Descarte voluntario de la captura incompleta
Dado que el sistema me ofreció retomar una captura no finalizada
Cuando elijo la opción de descartar
Entonces la aplicación elimina los datos temporales del borrador y me deja listo en la pantalla principal para iniciar una nueva consulta o registro de medidor

### Escenario: Ausencia de borradores pendientes
Dado que finalicé exitosamente el registro anterior o no dejé ningún proceso abierto
Cuando inicio o reabro la aplicación
Entonces no se presenta ningún diálogo de recuperación e ingreso de inmediato a la vista principal habitual
