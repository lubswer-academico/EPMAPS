# HU-002 – Búsqueda y consulta de medidores con soporte de caché

- **Identificador:** HU-002
- **Usuario:** Técnico de Campo
- **Prioridad para el negocio:** Alta
- **Riesgo para desarrollo:** Medio

## Descripción

Como técnico de campo, quiero consultar los datos registrados de un medidor ingresando su código oficial, para verificar su ubicación, historial de consumo y propietario antes de registrar la nueva lectura, sin tener que esperar descargas repetidas si ya lo consulté antes.

## Criterios de aceptación

### Escenario: Búsqueda exitosa con conexión a internet
Dado que tengo señal celular y me encuentro en la pantalla de búsqueda
Cuando ingreso un código de medidor completo con formato válido (prefijo "MED-" y seis dígitos)
Entonces el sistema consulta a la oficina y me muestra en pantalla la dirección, sector, número de cuenta, estado del suministro, última lectura registrada con su fecha y el consumo promedio mensual

### Escenario: Bloqueo de consulta con código incompleto
Dado que estoy en la pantalla de búsqueda de medidores
Cuando escribo un código que no cumple con el formato exacto de seis dígitos numéricos tras el prefijo "MED-"
Entonces el sistema deshabilita la acción de consulta y me advierte que el código está incompleto para evitar peticiones erróneas

### Escenario: Consulta rápida desde la memoria caché durante la jornada
Dado que ya consulté un medidor previamente durante el día y sus datos se encuentran guardados en el teléfono
Cuando vuelvo a ingresar el mismo código de medidor
Entonces la aplicación muestra sus datos de inmediato sin realizar una nueva descarga por internet

### Escenario: Medidor no encontrado en el sistema
Dado que tengo conexión y escribo un código con formato válido
Cuando el código no corresponde a ningún medidor registrado en el sistema de la oficina
Entonces la aplicación me informa que el medidor no fue encontrado y me permite corregir el código ingresado
